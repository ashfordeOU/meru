Check it offline

The scorecard is a signed verdict. Save it, then check it with Kshana Pro against the service's public key:

kshana-pro verdict verify scorecard.json --trust <service public key>

Each verdict the policyholder shared can be checked the same way. A verdict that does not verify was changed or was not issued by this service.
